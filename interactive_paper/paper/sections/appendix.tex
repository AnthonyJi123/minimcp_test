\section{Judge and self-evaluation prompts}
\label{app:prompts}

All adequacy labels use the following fixed system prompt
(\texttt{gpt-5.4-mini}, low reasoning effort, OpenAI Structured Outputs
with a strict \{\texttt{reason}, \texttt{adequate}\} JSON schema; the
judge never sees which system produced the answer):

\begin{quote}\small\ttfamily
You are a strict, fair grader of a small language model's answers. You
are given a QUESTION, an optional REFERENCE answer, and a CANDIDATE
answer produced by a small model. Decide whether the CANDIDATE is
ADEQUATE, meaning ALL of: (1) factually correct; (2) any reasoning
shown is valid; (3) it actually and completely answers the question
that was asked. For multiple-choice questions the candidate must land
on the correct option (by letter or by unambiguously stating the
option's content). A partially correct, hedged, refused, off-topic, or
truncated answer is NOT adequate. If a REFERENCE is provided, grade
against it. Be strict but do not penalize harmless differences in
format or extra correct detail.
\end{quote}

The verbalized self-evaluation baselines (\S\ref{sec:rq1}) use one fixed
phrasing each; $P(\text{Yes})$ is read from the first generated token's
distribution:

\begin{quote}\small\ttfamily
[pre] I am going to show you a question. Do NOT answer it. Judge
honestly whether you yourself would answer it correctly.
Question: \{q\}
Would you answer this question correctly? Reply with exactly one word:
Yes or No.

[post] Here is a question and a proposed answer.
Question: \{q\}
Proposed answer: \{a\}
Is the proposed answer correct? Reply with exactly one word: Yes or No.
\end{quote}

\section{Reproducibility}
\label{app:repro}

All sampling and splits use a fixed seed (42); the calibration/test
split is frozen once and the test split is touched only by the
evaluation scripts. Environment pins are listed in \S\ref{sec:setup}
(torch 2.8.0; transformers 4.51.0 for MiniCPM-o~4.5, with per-model
pins for the comparison backbones); all experiments run on single-H100
instances. Probe artifacts (weights, feature configuration, per-pool
label-free thresholds), the judge prompt above, all trace parquets, and
the per-experiment execution log --- including per-run GPU and API
spend, on the order of \$500 total across the project --- ship in the
project repository, released upon publication.
