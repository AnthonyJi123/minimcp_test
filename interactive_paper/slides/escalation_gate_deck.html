Design
02 — how the gate worksone dot product on a hidden state

The model already knows. We read it at the right depth.

A linear probe on one hidden state the forward pass is computing anyway.

  • Read point — layer 22 of 36, last token, at end of turn.
  • Cost — 20 ms text / 45 ms audio, before the first token.
  • Threshold = budget — one score per turn, three tiers.
  • Zero gradient steps on the 9B model.
0.879gate AUC, held-out test speech

03 — training receiptwhat was fitted, on what, against which baseline

The recipe, and the receipt

input   h(L22, last token), 4096-d
       read at assistant-start, end of turn
label   did the local model fail this query?
       blind judge vs reference answers
data    600 frozen public-benchmark queries
       360 calibrate / 240 test · seed 42
model   logistic regression, C = 0.001
       5-fold out-of-fold on the 360
output  one score per turn
       threshold = quantile = escalation budget

06 — transferfrozen gate, frozen thresholds, zero recalibration

It ports to benchmarks it has never seen

SD-QA — real human recordings. Every arm sits between the two lines that matter: the local-only floor it starts from and the cloud ceiling it walks toward.

Speech Web Questions — the same frozen gate, priced in seconds of response latency.

Speech TriviaQA 62.0 → 78.4 % · Speech WebQ 41.2 → 60.4 % · SD-QA 49.5 → 72.0 % at 44–47 % escalation, 250 queries per pool, each benchmark's own official audio. Gate AUC holds at 0.68–0.76 out of distribution, precision lift 1.33–1.35× on every pool.

07 — nextwhere the project goes

What we do next

  • Wider calibration — more queries per pool, more model families. The clearest lever on selectivity.
  • Per-domain threshold rescaling — one budget knob that means the same thing on every domain.
  • Spoken output and barge-in in the live loop — the last gap between the measured loop and a shipped assistant.
A 9B on-device model can tell, in 22 ms and without a single gradient step, when to let a bigger model answer — worth up to 25 accuracy points.
Appendix
A1 — ablation · depthprobe transfer by layer · text vs audio input

Why layer 22 — and why the last text layer drops

audio input text input MiniCPM-o 4.5 · last-token probe · transfer to a held-out query pool
  • Peak is mid-network — 0.931 at L22 against 0.366 at the final layer; L20–L30 is a plateau.
  • The drop is a readout, not the knowledge — audio input shows none of it, and mean-pooling still reads it at the final layer.
  • Not earlier — L10 gives 0.794, and early layers are modality-specific.
  • Reading at ~60 % depth sidesteps it entirely.
A2 — ablation · where to forkdecision quality vs decision time

The best layer is also the early one

One point per decoder layer: decision quality against how long prefill must run to reach it. Audio has the same shape, ~20 ms later.

  • Position — last token beats mean-pooling at the deployed layer.
  • Read point — end-of-turn 0.887 vs 0.764 per-chunk; hardest pool fires 20 % → 90 %.
  • Cross-modal — text-trained probe scores audio states at 0.855: calibrate typed, deploy spoken.
  • Signal ranking — mid-layer probe +0.064 > self-check +0.059 > final layer +0.054 > query router +0.040.
